PRISMA

Abrir o site

O Prisma é um site interativo de recomendação de viagens que funciona como um "teste de afinidade" ou guia de bolso inteligente. O projeto foi pensado para solucionar um problema comum: a indecisão na hora de planejar as férias ou a próxima viagem.

Protótipo

Abrir o protótipo

O protótipo desenvolvido no Figma contempla fluxos completos para desktop e mobile, guiando o usuário desde a tela de boas-vindas até um painel de resultados detalhado com percentuais de compatibilidade, tags informativas e sugestões personalizadas de destinos

Design System

Abrir o design system

O Design System do Prisma centraliza as diretrizes visuais e os componentes da interface, garantindo consistência, acessibilidade e uma experiência de usuário harmoniosa em diferentes dispositivos
